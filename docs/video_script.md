## PRODUCTION NOTES

**Audio sources needed:**
- Billie Jean official audio (licensed or YouTube link)
- Stem isolation: bass only, drums only (use Spleeter or lalal.ai)
- Synth demos: already generated in the website's Web Audio engine — record from browser

**Software:**
- DaVinci Resolve (free) or CapCut for text animation
- Spleeter (Python) or lalal.ai for stem separation
- OBS to record the website's audio player for synth demos

**Text animation style:**
- Fade in, 0.3s — hold — fade out, 0.2s
- No slide effects. Pure opacity transitions only.
- Font: Playfair Display (serif) for quotes, Inter (sans-serif) for labels

**Diagrams:**
- Use the 6 PNG files already generated
- Hold each diagram for minimum 8 seconds
- Add subtle Ken Burns zoom (1.0→1.04) over the hold
