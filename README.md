**A multimedia music analysis essay published on Yield · The Chronicles of Financial Markets**

By Solomon Von Herclestein

---

## Overview

A rigorous structural analysis of Michael Jackson's *Billie Jean* (1982), combining:

- Musicological analysis (F♯ Dorian mode, polyrhythm, counterpoint)
- Historical genealogy (Vangelis → Jon Anderson → Quincy Jones → Michael Jackson)
- Interactive Web Audio API synthesizer demonstrating each musical concept
- 6 original rhythmic/harmonic diagrams
- Connection between musical theory and financial market analysis

## Musical Key Facts

- **Key:** F♯ Dorian (not natural minor — raised 6th = D♯)
- **BPM:** 117
- **Bass pattern:** F♯ C♯ E F♯ E C♯ B C♯ (8 eighth-notes per bar)
- **Chord cycle:** F♯m → B → C♯m → E (no dominant, no resolution)
- **Snare:** reverb pre-delay engineered by Bruce Swedien
