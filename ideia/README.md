# Ideia

**Tese:** *Billie Jean* é um objeto de estudo estrutural — e a mesma lógica de tensão sem resolução que sustenta o groove (harmonia modal, deslocamento rítmico, silêncio funcional) ajuda a ler mercados de renda fixa.

**Voz autoral:** Solomon Von Herclestein — formação em conservatório (piano, violão clássico, contrabaixo), harmonia com Hans-Joachim Koellreutter. Tom: erudito, irônico com o "rockeiro de planilha", sem panfleto.
